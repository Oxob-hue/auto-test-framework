| 执行方式 | 耗时 | 说明 |
|----------|------|------|
| 顺序执行（默认，参考） | 63.93s | 单进程（加固前实测；加入 React 稳健等待后更慢，批量建议并行） |

> 并行数量受浏览器实例与机器 CPU 影响，可按需调整 `-n`。
