5. 稳定性与效率

项 结果
失败重试策略 仅对基础设施类异常（浏览器/驱动/网络）重试 1 次；断言失败不重试；本轮 47 条中触发 1 次重试并自愈
失败可观测 自动附加：运行日志尾部 + 页面截图 + DOM 源码 + 浏览器 Console 日志
跨环境一致性 同一套用例在本地 Edge（有头/无头）下均通过（47/47）；CI Chrome 无头此前已验证机制有效（环境变量切换浏览器 / 无头）
并行执行 pytest -n 4 全量 62.14s；单进程无头全量 191.12s
重复执行 数据前置创建 + 幂等清理；47 条用例反复执行无残留

6. 风险与遗留问题

项 说明 处理
公开环境波动 可能整批 ERR_CONNECTION_* 导致误报 已由"仅基础设施类重试"覆盖，重跑即恢复

7. 结论与建议

  • 结论：47 条自动化用例全部通过，覆盖接口契约/边界/幂等语义与 Web 端到端业务规则 （含访问控制与金额计算），可作为持续回归基线；流水线具备"提交即回归 + 报告自动发布"能力。
