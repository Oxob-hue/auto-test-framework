## 3. 覆盖情况

| 覆盖维度 | 覆盖情况 |
|----------|----------|
| 接口方法覆盖 | GET / POST / PUT / DELETE 全覆盖 |
| 接口状态码覆盖 | 200（成功）、404（资源不存在）、400/200（非法入参容错） |
| 等价类覆盖 | `status` 三取值全覆盖；非法取值单独覆盖 |
| 边界数据覆盖 | 中文 + 表情符号、256 字符超长名称、随机大 ID |
| 幂等/覆盖语义 | 同 ID 重复创建以最后一次为准；PUT 不存在 ID 行为自洽 |
| 接口契约覆盖 | Content-Type、响应耗时、jsonschema 结构 |
| Web 用户路径 | 登录（正/反）→ 列表（排序/详情/加购/移除）→ 购物车（空态/继续/部分移除）→ 结算（金额/取消/校验）→ 下单完成 → 退出登录 |
| 安全/访问控制 | 未登录直接访问受保护页面被重定向（2 条） |
| 业务规则 | 金额计算（小计 + 税费 = 总计）、购物车数量一致性、表单必填校验 |

## 5. 稳定性与效率

| 项 | 结果 |
|----|------|
| 失败重试策略 | 仅对基础设施类异常（浏览器/驱动/网络）重试 1 次；断言失败不重试；本轮 53 条中触发 1 次重试并自愈 |
| 失败可观测 | 自动附加：运行日志尾部 + 页面截图 + DOM 源码 + 浏览器 Console 日志 |
| 跨环境一致性 | 同一套用例在本地 Edge（有头/无头）下均通过（53/53）；CI Chrome 无头此前已验证机制有效（环境变量切换浏览器 / 无头） |
| 并行执行 | `pytest -n 4` 全量 62.14s；单进程无头全量 191.12s |
| 重复执行 | 数据前置创建 + 幂等清理；53 条用例反复执行无残留 |

## 6. 风险与遗留问题

| 项 | 说明 | 处理 |
|----|------|------|
| 公开环境波动 | 可能整批 `ERR_CONNECTION_*` 导致误报 | 已由"仅基础设施类重试"覆盖，重跑即恢复 |
| 浏览器渲染差异 | 个别浏览器/无头下表单错误提示不渲染 | 负向断言采用"业务规则 + 文案可选校验" |
| 覆盖范围 | 未覆盖性能基线（仅 1 条响应耗时契约）、安全专项、多浏览器矩阵 | 属范围外，可作为后续扩展 |
| CI 时长 | 用例扩充后 Web Job 时间增长（约 3~6 分钟） | 已支持 `-n` 并行；必要时在 CI 启用 |

## 7. 结论与建议

- **结论**：53 条自动化用例全部通过，覆盖接口契约/边界/幂等语义与 Web 端到端业务规则
  （含访问控制与金额计算），可作为持续回归基线；流水线具备"提交即回归 + 报告自动发布"能力。
- **建议**：
  1. CI 中可开启 `pytest-xdist` 并行以控制时长；
  2. 关注 `problem_user` 两个已知缺陷是否被官方修复，可转为回归用例；
  3. 视需要补充性能基线与多浏览器矩阵。
